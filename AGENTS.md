# Folder/Workspace description
A monorepo for a personal London EDM and live gig tracker, designed to discover upcoming shows across major city venues by artist. It consists of a decoupled .NET Minimal Web API backend that aggregates and normalizes external event data, paired with a dedicated frontend client (not yet created) for searching artists and managing a personal watchlist.

## Operational Routing

  - For backend work: refer strictly to `backend/AGENTS.md`
  - For frontend work: refer strictly to `client/AGENTS.md`
